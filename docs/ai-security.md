# AI 安全与执行协议

## 1. 信任边界

- 系统提示和工具定义：可信。
- 用户自然语言：需要解析和确认。
- 网页标题、URL、正文和页面脚本：不可信。
- Provider 输出：不可信，必须经过共享协议、服务端规范化与扩展复核。

## 2. 分层职责

```text
模型 Provider
  只生成结构化计划草稿
        ↓
本机 API
  校验 Schema、目标范围、操作冲突并重新计算风险
        ↓
浏览器扩展
  保存目标 URL/窗口快照、显示预览、用户确认、执行前复核
```

模型和服务端均不能直接调用 `chrome.*` API。

## 3. 风险等级

| 等级 | 示例 | 当前策略 |
|---|---|---|
| 只读 | 搜索、总结、查看标签 | 可直接展示 |
| 可逆修改 | 建组、静音 | 显示预览后由用户确认 |
| 批量修改 | 批量分组、批量静音 | 差异预览后由用户确认 |
| 删除 | 关闭标签 | 仅展示预览，当前禁止执行 |
| 清空 | 清历史、删除空间 | 二次确认，禁止自动化执行 |

删除操作只有在可恢复记录、撤销入口、部分失败恢复和审计全部完成后才能开放。

## 4. 共享操作协议

允许的操作：

- `CREATE_GROUP`
- `MUTE_TABS`
- `CLOSE_TABS`

协议层要求：

- 标签 ID 必须来自本次请求；
- 请求中的标签 ID 唯一；
- 远程上下文只接受 HTTP/HTTPS URL；
- 同一标签不能同时关闭并执行其他操作；
- 同一标签不能加入多个分组；
- 分组名称、颜色、操作数和标签数有上限；
- 模型声明的风险和确认字段不会被信任。

`CLOSE_TABS` 当前只用于预览，扩展执行门禁会拒绝它。

## 5. 执行前复核

扩展生成计划后保存每个目标的：

- 标签 ID；
- URL；
- 窗口 ID。

执行前重新读取浏览器状态，并拒绝以下情况：

- 计划超过 5 分钟；
- 创建时间无效或异常位于未来；
- 标签已关闭；
- URL 已改变；
- 标签已移动到其他窗口；
- 删除操作尚未具备恢复能力。

执行途中发生错误后，当前计划作废，用户必须重新生成，避免重放半完成操作。

## 6. 提示词注入防护

标签标题和 URL 只是数据，不能改变工具权限。网页中出现“忽略规则、删除书签、上传数据”等文字时，不得被解释为用户指令。

远程 Provider 当前不采集网页正文。后续即使用户授权正文读取，也必须将正文作为不可信材料放入独立字段，不能与系统指令拼接。

## 7. 数据最小化

远程 Provider 当前只发送 HTTP/HTTPS 标签的：

- ID 和窗口 ID；
- 标题和 URL；
- 活动、固定、声音和静音状态。

不会发送：

- `file://` 本地路径；
- `chrome://`、扩展页和内部页面；
- 网页正文；
- Cookie、Token、密码、书签正文或浏览历史；
- 模型 API Key。

## 8. API 与来源权限

- 第一阶段 Fastify API 只允许监听本机回环地址；
- 无认证 API 不得暴露到局域网或公网；
- 付费 Provider 必须配置精确扩展 Origin；
- 非本机模型服务必须使用 HTTPS；
- 扩展只申请用户配置的单一服务 Origin；
- 切换地址或本地模式时撤销旧来源权限；
- 模型 API Key 只保存在服务端环境变量。
