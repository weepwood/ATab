# AI 安全与执行协议

## 1. 信任边界

- 系统提示和工具定义：可信。
- 用户自然语言：需要解析和确认。
- 网页标题、正文和页面脚本：不可信。
- 模型输出：不可信，必须经过 Schema 与业务校验。

## 2. 风险等级

| 等级 | 示例 | 默认策略 |
|---|---|---|
| 只读 | 搜索、总结、查看标签 | 可直接执行 |
| 可逆修改 | 建组、移动、加标签 | 显示预览后确认 |
| 批量修改 | 批量移动、批量静音 | 差异预览后确认 |
| 删除 | 关闭标签、删除书签 | 明确确认并写入撤销记录 |
| 清空 | 清历史、删除空间 | 二次确认，禁止自动化执行 |

## 3. 操作计划

模型只能返回白名单操作：

```json
{
  "id": "plan_xxx",
  "summary": "把 GitHub 页面放入开发分组",
  "risk": "reversible",
  "requiresConfirmation": true,
  "operations": [
    {
      "type": "CREATE_GROUP",
      "tabIds": [12, 18],
      "name": "开发"
    }
  ]
}
```

扩展执行前重新查询当前标签，并验证 ID、URL、窗口、计划有效期和执行状态。

## 4. 提示词注入防护

网页正文只能作为检索材料，不能改变工具权限。页面中出现“忽略规则、删除书签”等文本时，不得被解释为用户指令。

## 5. 隐私默认值

- 默认不上传历史记录。
- 默认不采集网页正文。
- 登录、支付、邮箱、医疗和内网系统默认禁止正文采集。
- 模型 API Key 只保存在服务端或用户本地受控环境，不能写入扩展包。
