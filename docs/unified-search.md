# 跨数据源统一搜索

ATab 统一搜索将多个浏览器数据源转换为统一的本地搜索文档，然后使用确定性评分函数排序。

## 数据源

当前支持：

- 当前打开的标签页；
- Chrome/Edge 原生书签；
- ATab 云收藏；
- 手动会话和自动快照；
- 用户已经授权的浏览历史。

统一搜索不会为了增加历史结果而主动申请 `history` 权限。没有权限时只跳过历史来源，其余数据源仍正常检索。

## 本地搜索协议

每个数据源适配为：

```text
id
source
targetId
action
title
subtitle
url（可选）
keywords
updatedAt（可选）
active（可选）
```

结果动作：

- 标签页：聚焦已有标签页；
- 原生书签、云收藏、历史：打开 URL；
- 会话：在新窗口恢复会话。

## 查询规则

查询文本会进行：

- Unicode NFKC 规范化；
- 大小写统一；
- 连续空白折叠；
- 按空格拆分关键词；
- 去除重复关键词。

多个关键词采用 AND 语义：每个关键词都必须命中标题、URL、标签/内容或说明中的至少一个字段。

## 评分

评分从高到低大致为：

1. 标题完全匹配；
2. 标题前缀匹配；
3. 标题包含；
4. URL 匹配；
5. 标签、备注、会话内页面等关键词匹配；
6. 来源说明匹配。

额外有限加权：

- 当前活动标签页；
- 近期更新或访问的内容；
- 云收藏、标签页等高频操作来源。

来源权重只用于分数接近时的排序，不会覆盖明显更强的文本匹配。

## 性能策略

- 输入防抖 180ms；
- 搜索代次防止旧异步结果覆盖新查询；
- 浏览历史单次最多读取 500 条匹配项；
- 最终结果默认最多返回 120 条；
- 评分引擎硬上限 500 条结果；
- 查询为空时不读取各数据源。

当前实现适合数千条书签、云收藏和会话。数据规模进一步增长后，应增加增量内存索引或 IndexedDB 全文索引。

## 键盘操作

- `Ctrl + K` / `Command + K`：从任意工作台打开搜索并聚焦输入框；
- `↑` / `↓`：切换选中结果；
- `Enter`：执行结果动作；
- `Esc`：清空查询。

## 隐私边界

- 搜索词和结果仅在扩展本地处理；
- 不发送给 AI Provider；
- 不发送给同步 API；
- 不写入同步 Outbox；
- 不持久化搜索历史；
- 不自动扩大浏览器权限。

## 当前限制

- 当前是关键词搜索，不是向量语义搜索；
- 尚未支持中文拼音和模糊纠错；
- 尚未搜索网页正文；
- 尚未提供命令工具调用，例如直接输入“关闭重复标签”；
- 会话结果的执行会恢复窗口，当前没有二次预览。
